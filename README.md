# 部品ストック

手持ちの電子部品を管理する在庫台帳アプリです。部品名・値や型番・形状・保管場所・数量を記録し、検索やカテゴリでの絞り込み、残りわずかな部品の確認ができます。

## 使い方

| 場所 | できること |
| --- | --- |
| [claude.ai の部品ストック](https://claude.ai/artifact/VGvNWGs9um8YHkDYHopM64) | 在庫の追加・編集・数量の増減（本体） |
| GitHub Pages（このリポジトリの `index.html`） | バックアップ時点の在庫を閲覧専用で表示 |

在庫データの本体は claude.ai 上の台帳にあります。このリポジトリには、アプリのコードと在庫データのバックアップを置いています。

## ファイル構成

```
index.html        アプリ本体（1ファイル完結）
data/parts.json   在庫データのバックアップ
data/parts.csv    同じ内容のCSV（Excel・Googleスプレッドシートで開ける）
```

## データの項目

| 項目 | 内容 | 例 |
| --- | --- | --- |
| `name` | 部品名 | 抵抗 10kΩ |
| `category` | カテゴリ | 抵抗 / コンデンサ / IC・マイコン / センサ など |
| `spec` | 値・型番 | 1/4W ±1% 金属皮膜 |
| `package` | 形状・パッケージ | リード / 3ピン基板 |
| `location` | 保管場所 | 棚A-1 |
| `qty` / `unit` | 数量と単位 | 20 本 |
| `minQty` | これ以下で「残りわずか」表示 | 5 |
| `link` | データシートや購入先のURL | |
| `notes` | メモ | |

## バックアップの更新

claude.ai で Claude に「部品ストックをGitHubにバックアップして」と頼むと、最新の在庫を `data/` に書き出してコミットします。
